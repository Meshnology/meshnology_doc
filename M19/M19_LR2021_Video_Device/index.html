M19 LR2021 Video Device

Product Overview​

The M19 LR2021 Video Device (Multimedia LoRa Dev Terminal) is a multimedia LoRa development board built around an ESP32-S3R8 dual-core MCU (up to 240 MHz, 8 MB OPI PSRAM + 16 MB Flash) and the fourth-generation LR2021 LoRa transceiver.

Compared with OLED-only boards, M19 adds a 1.22-inch 240×240 colour LCD, a DVP camera, MicroSD storage, and LoRa image / short-video transmission, while keeping full-band Wi-Fi 4 + BLE 5.0 + dual-band LoRa (Sub-1 GHz and 2.4 GHz). Local UI navigation is handled by the on-board BOOT key and an ADC five-way key (up / down / left / right / center).

Typical uses include field video snapshot over LoRa, portable inspection terminals, outdoor GNSS-assisted nodes, and multimode IoT prototyping.

MeshCore firmware

You can flash official MeshCore firmware for M19 online via the Web Flasher using Method B: Pick a device → select M19 Meshnology LCD (MeshCore, ESP32-S3).
For factory / peripheral demos from this wiki, use Method A with files from M19_Demo_Details.rar.

Product Features​

  • Multimode wireless: Wi-Fi 4 (2.4 GHz), BLE 5.0, and LR2021 LoRa on Sub-1 GHz + 2.4 GHz paths
  • Multimedia: 240×240 LCD preview, DVP camera, JPEG image / short-video transfer over Sub-G FLRC
  • Positioning: External GNSS module interface (GPS / BDS / GLONASS / QZSS class support in factory firmware)
  • Storage: MicroSD card slot (SPI; hot-plug not supported)
  • Human interface: RST, BOOT/USER, RGB status LED, and five-way navigation key
  • Power options: USB Type-C (5 V / 1 A), lithium battery (3.3–4.2 V), solar input (approx. 5 V / 1 A to 12 V / 0.4 A)

Setting up the environment​

Download and install the Arduino IDE​

Arduino download site: arduino.cc/en/software

Download and install the software following the Arduino installation instructions.

Installing the ESP32 development board​

  • To use ESP32-based boards in the Arduino IDE, you must first install the “esp32 by Espressif Systems” board package.
  • Install in accordance with the panel installation requirements.

Once you have opened the software:

File → Preferences

Add the address of the development board manager:

  • Link to the stable release:

    https://espressif.github.io/arduino-esp32/package_esp32_index.json

  • Link to the development version:

    https://espressif.github.io/arduino-esp32/package_esp32_dev_index.json

When you have finished, select OK.

  • Select the Boards Manager on the left-hand side of the software
  • Search for esp32 in the search bar
  • In the version field for the “esp32 by Espressif Systems” development board found in the search results, select a version of 3.2.0 or higher
  • Click to install

  • Once you click it, a message like this will appear in the bottom-right corner of the software; please wait for the download to complete (ensure you have a stable internet connection whilst waiting).

  • Once the download is complete, a success message will appear

  • When you search again, the word INSTALLED will appear

Install the required libraries​

When installing Arduino libraries, there are usually two options available: online installation and offline installation. If a library requires offline installation, you must use the provided library files. For most libraries, users can easily search for and install them via the Arduino software’s online library manager. However, some open-source or custom libraries are not synchronised with the Arduino library manager and therefore cannot be obtained via an online search. In such cases, users must install these libraries manually using the offline method.

As the library files for this product are already included in the sample package, there is no need to download any additional libraries.

Firmware flashing​

M19 uses the Meshnology Web Flasher. No separate desktop flashing utility is required.

Preparation​

  • Hardware: M19 development board, Type-C USB data cable (must support data transfer)
  • Software environment: Use a Chrome or Edge browser (must support Web Serial). No additional software installation is required.
  • Access the tool: Open https://meshnology-flasher.pages.dev/
Serial port not detected

If your computer cannot detect the device when clicking Choose serial port, press and hold the BOOT button on the development board, then press and release the RST button. Keep holding BOOT until the computer recognizes the serial port. You can release BOOT once the device is connected.

Flashing steps​

1. Select chip type​

In the Connect device panel on the left, select ESP32 family from the CHIP FAMILY dropdown menu. If you are connecting an ESP32-S3 device such as the M19, the tool will automatically detect the chip model.

2. Select firmware​

Choose one of the following two methods depending on your needs:

Method A: Local upload (recommended)

  • Single merged .bin: Click browse from your computer or drag and drop the merged .bin file into the dashed box. This is the fastest method.
  • Multiple files + offsets: Open the Multiple files + offsets tab, add the bootloader, partition table, application files, and fill in the correct offset addresses.

Method B: Pick a device (official online firmware, including MeshCore)

Use this method to flash cloud-hosted firmware such as MeshCore (no local .bin required).

  1. Click the Pick a device tab.
  2. In DEVICE, select M19 Meshnology LCD (MeshCore, ESP32-S3) (latest version, for example 1.0.0).
  3. The tool automatically matches the MeshCore firmware image and recommended flash parameters.
MethodTypical use
Method A — Local uploadFactory / peripheral demos from M19_Demo_Details.rar, or your own *.merged.bin
Method B — Pick a deviceOfficial MeshCore firmware for M19 (online)

3. Choose serial port​
  1. Click the green Choose serial port button on the left.
  2. In the browser serial port selection window, select the corresponding device port (usually displayed as USB JTAG/serial debug unit or COMx) and click Connect.
4. Configure flash parameters (optional)​

In the Flash parameters section:

  • Default: Keep MODE, FREQUENCY, and FLASH SIZE all set to Auto.
  • Manual specification: If Auto fails, manually select:
    • MODE: DIO
    • FREQUENCY: 80 MHz
    • FLASH SIZE: 16 MB

5. Start flashing​
  1. Click the blue Flash single file button at the bottom to start flashing.
  2. Observe the TERMINAL window below; it will show erase and write progress (for example, Writing at 0x... (xx%)).
  3. Wait for the progress bar to reach 100%. When the terminal finally displays Done. and [esptool] board reset, the firmware has been written successfully.
  4. The device will automatically reset and reboot. If it does not reboot automatically, manually press the RST button on the development board to complete the flashing process.

Demo_01_Factory​

Programme Description​

The M19 demo firmware is a comprehensive factory test and function demonstration firmware developed for the ESP32-S3R8 (16MB Flash + 8MB OPI PSRAM) development board. The UI uses an LVGL 8.4.x left-right page-turning (Tileview) design. The pages include: Detect → Status → WiFi&BLE → LoRa Six States → LoRa Image Transmission → Camera Preview. It supports page turning and function switching via the BOOT key and ADC five-way key, and includes battery ADC, RGB LED, and deep-sleep standby functions.

Boot Process​

After power-on, the device automatically runs the initialization self-test process and stays on the Detect page by default. This page displays whether peripherals such as LCD / SD / Camera / GPS / LoRa / WiFi / BLE were initialized successfully.

UI Page Overview​

PageFunction Description
DetectDisplays whether LCD / SD / Camera / GPS / LoRa / WiFi / BLE were initialized successfully
StatusRuntime status summary (including battery voltage, GPS positioning information, latitude/longitude/satellite count, device SN, etc.)
WiFi&BLEWiFi STA (default SSID/connection status/IP/RSSI), BLE peripheral name/connection status/received packet preview; WiFi/BLE are actually loaded only when entering this page
LoRa Six StatesIncludes six working states: SubG_RX / SubG_TX / SubG_CW / 2G4_RX / 2G4_TX / 2G4_CW
LoRa ImageSub-G FLRC image transmission (JPEG), supports TX/RX, short video, broadcast listen-only RX
CameraDVP RGB565 camera preview (FB in PSRAM)

Key Operations and System Mechanisms​

  • BOOT key (short press): Next page; short press on the LoRa page switches modes.
  • ADC five-way key (up/down/left/right/center): Controls page turning / LoRa state switching / TX-RX-shooting on the image page, etc.
  • Power/deep-sleep mechanism: The device automatically enters deep-sleep mode after about 10 minutes of inactivity; long-pressing the BOOT key can trigger the shutdown/standby path.

LoRa Test Instructions​

ItemParameter/Description
LoRa ModuleLR2021 (supports Sub-G and 2.4G)
Working ModesKey cycles through Sub-G / 2.4G RX, TX, CW (six states in total)
Image TransmissionSub-G FLRC image transmission (JPEG, esp_new_jpeg)
Critical resource management
  • SPI bus sharing: LCD / LoRa / SD share the same bus. In LoRa TX/CW mode or during image transmission, the system automatically freezes LVGL and yields the shared SPI to the RF to prevent display corruption.
  • Memory and DMA staggering: Arduino internal RAM is relatively tight. WiFi, Camera DMA, and BLE need to be staggered; when entering the LoRa/Image/Camera pages, the system automatically suspends WiFi+BLE to free up contiguous internal DMA blocks.

Quick Operation Reference​

OperationEffect
Power onAutomatic initialization, enters the Detect page
Page turning (Detect → Status → WiFi&BLE → LoRa → Image → Camera)Left/right five-way key / BOOT short press
Up/down five-way key / BOOT short press (on LoRa page)Switch among six states (RX/TX/CW, etc.)
Center key / BOOT short press (on image page)Control TX/RX start/stop, pause/shoot
Serial monitor (115200)View boot logs and initialization status of each peripheral
Common troubleshooting
  • BLE error HLI / IWDT: Confirm that the code includes esp32-hal-alloc-ble-mem.h and that a full rebuild has been performed.
  • WiFi NO_MEM + LCD SPI failure: Caused by internal RAM fragmentation. Do not forcibly enable WiFi and Camera DMA at the same time; follow the system's lazy-loading mechanism.

Hardware connections​

  • Connect the M19 board to the computer using a USB Type-C data cable.
  • Make sure the sample package libraries are installed in your Arduino libraries folder before compiling.

Demo_02_RGB​

Programme Description​

The M19 demo firmware (Demo_02) is a single-item module test firmware for the RGB LED on the ESP32-S3R8 (16MB Flash + 8MB OPI PSRAM) development board. The UI uses a simplified single-page design and supports switching and adjusting lighting effects, colors, and brightness via the BOOT key and ADC five-way key. It is used for rapid production-line verification of whether the RGB (TZH1010) driver and LED beads are functioning properly.

Boot Process​

After power-on, the device automatically runs the initialization process: it first performs a red → green → blue self-test flashing sequence, then stays on the RGB control page. This page displays the current lighting effect status.

UI Page Overview​

Screen ItemFunction Description
PowerLighting effect on/off status
ModeCurrent mode (Solid / Breath / Rainbow / Blink)
ColorCurrent color (Red/Green/Blue/Yellow/Purple/Cyan/White)
BriBrightness percentage

Key Operations and System Mechanisms​

  • CENTER key: Turn the RGB LED on or off (corresponds to the Power switch).
  • UP key / BOOT key (short press): Cycle through modes (Solid → Breath → Rainbow → Blink).
  • DOWN key: Decrease brightness (wraps around when reaching the minimum).
  • LEFT / RIGHT keys: Switch colors.
  • Power/deep-sleep mechanism: In the idle state, the current lighting effect is maintained (or as configured in the code). Long-pressing the BOOT key for about 1.5s can trigger deep-sleep shutdown.

Hardware connections​

Demo_07_SD​

Programme Description​

The M19 demo firmware (Demo_07) is a single-item module test firmware for the TF card (SD) on the ESP32-S3R8 (16MB Flash + 8MB OPI PSRAM) development board. The UI uses a simplified single-page design. On power-up, it automatically mounts the card and detects card information, and supports executing a read/write self-test via key press. It is used for rapid production-line verification of the SPI card slot and storage read/write functionality.

Boot Process​

Insert the TF card before power-on (or insert it after power-on). The device automatically runs the SD card detection and mounting process and enters the SD card information page by default.

UI Page Overview​

Screen ItemFunction Description
StatCard status (OK / none)
NameCID product name (may not match the nominal capacity, e.g., a 32G card may display SD16G; the actual capacity in the Size row prevails)
TypeCard type (SDHC / SDXC / SDSC)
SizeActual capacity (in MB)
SpeedOperating clock frequency
SectSector size
R/WRead/write test status (default --; after testing, displays OK or fail)

Key Operations and System Mechanisms​

  • Any direction key / BOOT key (short press): Execute the R/W read/write self-test. The system writes data to and reads data from /sdcard/m19_demo.txt.
  • Power/deep-sleep mechanism: Long-pressing the BOOT key for about 1.5s can trigger deep-sleep shutdown.

Hardware connections​

  • Connect the M19 board to the computer using a USB Type-C data cable.
  • Make sure the sample package libraries are installed in your Arduino libraries folder before compiling.

Demo_08_LORA​

Programme Description​

The M19 demo firmware (Demo_08) is a single-item module test firmware for the LoRa RF module (LR2021 module) on the ESP32-S3R8 (16MB Flash + 8MB OPI PSRAM) development board. The UI uses a simplified single-page design and supports switching between SubG (915MHz) and 2.4G bands for transmit/receive and continuous wave (CW) modes. It is used for rapid production-line verification of RF transmit/receive performance.

Boot Process​

After power-on, the device automatically initializes the LR2021 module and enters 915-RX (receive) mode by default.

UI Page Overview​

Screen ItemFunction Description
ModeCurrent RF mode (see mode sequence below)
Rssi / SNRReceived signal strength / Signal-to-noise ratio
TX / RXTransmit / receive packet counters
PwrCurrent transmit power level

Key Operations and System Mechanisms​

  • DOWN / CENTER key / BOOT key (short press): Switch to the next mode.
  • UP key: Switch to the previous mode.
  • Mode cycle order: 915-RX → 915-TX → 915-CW → 2.4G-RX → 2.4G-TX → 2.4G-CW → repeat.
  • Test instructions: It is recommended to use two devices, setting one to TX and the other to RX, and observe changes in Rssi/SNR and counters. CW mode is only for continuous wave testing; please comply with local radio regulations.
  • Power/deep-sleep mechanism: Long-pressing the BOOT key for about 1.5s can trigger deep-sleep shutdown.

Hardware connections​

  • Connect the M19 board to the computer using a USB Type-C data cable.
  • Make sure the sample package libraries are installed in your Arduino libraries folder before compiling.

Programme Description​
